# Jobflow (AI Resume Tailor) - Resume Dataset

## 🏷️ CATEGORY: BACKEND DEVELOPMENT & APIs
**Tech Stack:** Python, FastAPI, SQLAlchemy, Alembic, SQLite
* "Developed a high-performance RESTful backend using FastAPI and Python, structuring the application with clear separation of concerns (Routers, Services, Models, Schemas)."
* "Managed relational database schema evolution through Alembic migrations, utilizing SQLAlchemy ORM to safely handle complex user states and job application lifecycles."
* "Designed a dynamic templating engine using Jinja2, allowing for real-time rendering of complex HTML dashboards and customized, ATS-optimized print resumes."

## 🏷️ CATEGORY: WEB SCRAPING & AUTOMATION
**Tech Stack:** Playwright, DOM Parsing
* "Automated complex job description extraction and DOM parsing by integrating Playwright, utilizing persistent browser profiles to gracefully handle session caching and bypass anti-bot challenges."
* "Engineered a resilient data pipeline that transforms raw, unstructured web data from major job boards into structured JSON schemas for downstream AI processing."

## 🏷️ CATEGORY: AI & DATA PROCESSING
**Tech Stack:** Python, LLM Integration, JSON
* "Architected an AI-driven resume tailoring engine that reads a master JSON profile, maps candidate skills against scraped job descriptions, and dynamically generates hyper-relevant resume bullets."
* "Automated the generation of custom Markdown cover letters by feeding contextual job data and master profile history into a generative AI pipeline."

**Tech Stack:** Docker, Docker Compose, GKE (GCP), AKS (Azure), DOKS (DigitalOcean)
* "Containerized the full-stack FastAPI application using Docker and `docker-compose`, scripting automated pre-boot checks (`wait_and_migrate.sh`) to ensure database schemas are applied before server initialization."
* "Demonstrated robust multi-cloud container orchestration expertise, successfully migrating and maintaining Kubernetes deployments across Google Kubernetes Engine (GKE), Azure Kubernetes Service (AKS), and DigitalOcean Kubernetes Service (DOKS)."
